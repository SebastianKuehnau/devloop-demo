# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Stack

Demo project for the Vaadin Dev Loop (see `README.md`): Java 25, Spring Boot 4.1.2, Vaadin 25.3.5 (Flow, Java UI, Aura theme), DevTools. Vaadin versions are managed via `vaadin-bom` in `pom.xml`. Coordinates: `com.vaadin.demo:devloop-demo`.

Base package is `com.vaadin.demo.devloop`. Entry point: `Application` (also the `AppShellConfigurator`, loads `Aura.STYLESHEET` and `styles.css`). No views, entities, or services exist yet.

- App CSS: `src/main/resources/META-INF/resources/styles.css`
- Config: `src/main/resources/application.properties`
- `src/main/frontend/generated/` is generated by the build — never edit.

## Vaadin Dev Loop

`vaadin-dev` is already a dependency in `pom.xml`, but the Dev Loop CLI and skills are **not installed** in this checkout (no `.vaadin/`, `.agents/` or `.claude/` directory). Install them with:

```bash
./mvnw vaadin:install-dev-cli
```

This creates `.vaadin/vaadin-dev` (the CLI), `.agents/skills/vaadin-devloop/` and `.claude/skills/vaadin-devloop/`. From then on, follow the `vaadin-devloop` skill:

- `.vaadin/vaadin-dev status` / `start` / `apply` / `restart` / `stop` / `shutdown`
- App on http://localhost:8080; logs in `target/devloop/`
- Never start the app via `./mvnw spring-boot:run` or an IDE run config (port 8080 conflict with the daemon), and use `apply` instead of `mvn compile` to check edits.

## Commands

- Tests: `./mvnw test` (no tests exist yet; `src/test` is absent)
- Package: `./mvnw clean package`
